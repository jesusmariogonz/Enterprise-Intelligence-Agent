# data/structured/

Base de datos transaccional ficticia de "EIA Corp", usada en los ejemplos
de consultas SQL del libro.

- `northwind.db` — base de datos Northwind en SQLite, obtenida de
  [84adam/northwind-SQLite3](https://github.com/84adam/northwind-SQLite3)
  (archivo `Northwind_small.sqlite`, renombrado). Incluye, entre otras,
  las tablas `Order` (830 filas), `Customer` (91), `Product` (77),
  `Supplier` (29) y `Employee` (9).
- `LICENSE_NORTHWIND.txt` — licencia original de Northwind (conservada
  intacta, sin modificaciones).
- `northwind_erd.png` — diagrama entidad-relación (ERD) de la base de
  datos, para referencia rápida del esquema.

**Origen:** los tres archivos se extrajeron del repositorio
`84adam/northwind-SQLite3` (no incluido como submódulo, solo como fuente
de los datos).
